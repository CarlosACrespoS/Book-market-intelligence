## 📌 Contexto y Oportunidad de Negocio

El surgimiento del COVID-19 reconfiguró los hábitos de consumo global. Con el cierre de espacios físicos, el hogar se convirtió en el epicentro del entretenimiento, disparando la demanda de plataformas de lectura digital. En este entorno de crecimiento acelerado, las *startups* no solo compiten por volumen, sino por la precisión de su oferta. 

Este proyecto realiza una auditoría integral a la base de datos de un competidor clave dentro del sector editorial digital para extraer los cimientos de una **propuesta de valor ganadora** en el mercado post-pandemia.
